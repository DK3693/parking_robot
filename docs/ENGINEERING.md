# Engineering design

## System decomposition

프로젝트의 핵심은 센서 인지, 기하 추정, 이동 제약 및 임무 상태를 독립적으로 정의한 뒤 명시적인 인터페이스로 연결하는 데 있습니다.

| 계층 | 입력 | 출력 | 구현 책임 |
|---|---|---|---|
| Sensor processing | LiDAR 관측, 카메라 영상, 센서 자세 | 공통 좌표의 점군, 차량 검출 | 측정 시각·좌표계 보존 |
| Axle estimation | 타이어 후보 점군 | 차량 방향, 타이어·차축 중심 | 기하 제약과 대표점 계산 |
| Alignment control | 관측 기반 목표 자세 | 접근·진입·보정 명령 | 재측정을 포함한 폐루프 수행 |
| Parking inventory | 영상 검출, 공간 관측 | 칸별 상태와 근거 | 관측 누적과 재관측 대상 관리 |
| Motion planning | 시작·목표, 장애물, 결합 형상 | 경로와 바퀴 명령 | 공간·조향·속도 제약 검사 |
| Mission management | 작업 요청, 이동·적재 상태 | 실행 단계, 대기 이유, 완료 상태 | 작업 ID와 자원 상태 추적 |
| Evaluation | 기록된 관측·명령·기준 자세 | 오차·시간·검사 결과 | 재현 가능한 정량 평가 |

## 2D LiDAR-based axle alignment

### Point-cloud geometry

각 센서 관측점을 센서 외부 파라미터를 이용해 로봇 공통 좌표계로 변환합니다.

$$
p^{base}=T^{base}_{sensor}\,p^{sensor}
$$

타이어 후보에 대한 점 수, 공간 범위와 좌우 기하 관계를 검사한 후 차량 방향과 차축 위치를 추정합니다. 센서 외부 파라미터는 점군 정합을 위한 값이며, 시뮬레이터의 차량 정답 자세는 장면 구성과 사후 오차 계산에 사용합니다.

### Quantile-based representative position

차량 종방향 단위벡터를 $u$, 타이어 관측점을 $p_i$라고 할 때 투영 좌표는 $s_i=u^T p_i$입니다. 고정 분위수 설정의 종방향 대표점은 다음과 같습니다.

$$
\hat c_{long}=\frac{Q_{0.05}(s)+Q_{0.95}(s)}{2}
$$

최종 타이어 위치 계산에서는 이 종방향 대표점과 횡방향 관측 평균을 결합합니다. 방향 재추정의 초기 대표점에도 동일한 통계량 설정을 적용합니다. 좌우 타이어 중심의 중점으로 차축 목표를 계산하고, 두 타이어의 연결 방향과 수직인 차량 길이 방향을 구합니다.

분위수 중점은 강건한 위치 요약을 위한 통계량입니다. 여기서는 이를 **타이어 관측 기하, 중심선 접근, 반복 위치 보정으로 연결한 정렬 파이프라인**으로 구현했습니다.

### Closed-loop motion

1. **관측 및 방향 추정:** 현재 센서 입력에서 차량 방향과 차축 목표를 계산합니다.
2. **중심선 접근:** 차량 길이 방향의 진입선에 로봇 위치와 자세를 맞춥니다.
3. **직선 진입:** 관측으로 계산한 차축 접근 위치까지 이동합니다.
4. **재측정 보정:** 새 관측으로 잔여 오차를 계산하고 위치·방향을 보정합니다.
5. **정렬 확인:** 센서 기반 정지 조건과 사후 기하 조건을 각각 확인합니다.

제어 목표를 정하는 추정기와 이동 구간의 충돌 검사는 역할을 분리했습니다. 센서 수, 차량 모델, 초기 조건 및 제어 조건을 명시한 시험에서 결과를 평가합니다.

## Parking-space perception

측면 카메라의 차량 검출과 LiDAR 공간 관측을 주차칸 좌표에 대응시켜 상태를 누적합니다.

- **관측 연결:** 영상·거리 관측에 측정 시각과 로봇 자세를 연결합니다.
- **칸별 증거:** 차량 검출, 점유 근거와 빈 공간 관측 범위를 칸별로 유지합니다.
- **상태 결정:** 점유, 빈칸, 추가 관측 필요 상태를 구분합니다.
- **재검사:** 미확정 칸을 복귀 경로에서 정지 관측 대상으로 관리합니다.
- **기록:** 원천 프레임, 시각과 판정 근거를 연결하여 영상과 결과를 대조할 수 있게 구성합니다.

차량 검출 점수와 최종 점유 판정은 서로 다른 정보입니다. 물체 검출 점수는 검출기의 출력으로 보존하고, 공간 관측 및 시간 누적의 결과와 함께 해석합니다.

## Assembly-aware motion planning

### Coupled geometry

운반체 기준 자세를 $q=(x,y,\theta)$, 차량 길이와 폭을 $L,W$, 모듈 간격을 $d$로 둡니다. 운반체의 점유 형상은 차량과 두 모듈의 변환된 형상을 합친 집합으로 표현합니다.

$$
\mathcal B(q;L,W,d)=\mathcal B_{vehicle}(q)\cup\mathcal B_{front}(q,d)\cup\mathcal B_{rear}(q,d)
$$

장애물 집합 $\mathcal O$에 대해 전체 이동 구간에서 $\mathcal B(q(t))\cap\mathcal O=\emptyset$인지 검사합니다. 중심점의 충돌 여부와 운반체 전체의 통과 가능성을 구분하는 모델입니다.

### Search, realization and validation

C-AWS 공개 구현의 탐색 코어를 기준으로 경로를 생성하고, 결합 형상 및 공통 제어 조건을 적용합니다. 결과는 다음 세 수준으로 분리해 평가합니다.

| 수준 | 평가 항목 |
|---|---|
| Geometric path | 목표 도달, 차량·모듈 외곽의 충돌, 구간 분리거리 |
| Wheel-command realization | 조향각, 조향 속도, 바퀴 구름 속도 및 가속도 |
| Kinematic consistency | 60 Hz 바퀴 명령 적분과 기준 궤적의 일치 여부 |

점 샘플 검사와 함께 구간 사이의 분리거리 하한을 검사합니다. 공개 데이터의 대표 출차 2건은 이 기하·명령 평가 수준의 결과입니다. C-AWS 탐색 코어의 활용, 결합체 검증, 공통 정지·조향 명령 실현을 구분하여 기록했습니다.

## ROS 2 mission orchestration

이동, 적재 및 주차칸 상태를 임무 제어기에 연결하고, 작업 ID를 중심으로 현재 단계와 응답을 관리합니다. 앞·뒤 모듈 한 쌍은 하나의 차량 운반체로 관리하며 세부 상태는 모듈별로 구분합니다.

공개 문서에서는 내부 명칭 대신 다음과 같은 논리적 인터페이스로 표현합니다.

| 논리적 인터페이스 | 대표 데이터 | 의미 |
|---|---|---|
| Localization | stamped pose, covariance, frame | 현재 위치와 추정 불확실도 |
| Parking inventory | bay ID, state, evidence | 칸별 점유 상태 |
| Mission status | request ID, stage, remaining steps | 임무 진행 상태 |
| Payload status | loading state, completion state | 적재 작업 응답 |
| Resource state | reservation, waiting reason | 공유 통로 사용 상태 |

관제 화면은 이 상태를 구독해 현재 위치, 목표, 작업 단계와 대기 이유를 표현할 수 있도록 설계했습니다. 상태 비교 코드는 공개 평가 도구로 포함했습니다.

## Physics diagnostics

PhysX 시험에서는 접촉 재질과 마찰 결합 규칙, 질량·관성, 구동 명령과 관절 응답을 구분해 기록했습니다. 각 접촉부의 수직력과 바퀴·조향 상태를 수집해 경로 기하와 접촉 동역학을 별도 계층으로 분석할 수 있는 진단 환경을 구성했습니다.

평가 대상은 바닥 재질 값 하나가 아니라 **접촉쌍, 하중 분포, 구동 상태와 차체 운동의 관계**입니다. 센서·운동학 시험과 접촉 동역학 시험은 서로 다른 평가 집합으로 관리합니다.

## Timestamp-aware state comparison

실물–모의 비교 입력은 동일한 지도 좌표, 측정 기준점, 시계와 시행 ID로 정합합니다. 공개 비교 도구는 이미 정합된 평면 상태를 입력받아 다음 처리를 수행합니다.

- 대응 시각 전후 샘플을 이용한 위치·각도 보간
- 각도의 주기성을 고려한 최단 방향 차이 계산
- 모의 방향 기준 종·횡방향 차이와 위치 차이 계산
- 좌표·지도·시계·시행·로봇·기준점·정합 ID의 일관성 검사
- 외삽과 과도한 관측 공백의 구분

$$
e_\parallel=\cos\theta_s\Delta x+\sin\theta_s\Delta y,\quad
e_\perp=-\sin\theta_s\Delta x+\cos\theta_s\Delta y
$$

$$
e_\theta=\operatorname{atan2}(\sin(\theta_r-\theta_s),\cos(\theta_r-\theta_s))
$$

각 입력이 추정 자세라면 결과는 두 추정값의 차이입니다. 독립 기준 측정이 있는 경우에 그 기준에 대한 정확도를 별도로 계산합니다.
