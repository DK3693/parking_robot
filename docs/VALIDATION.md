# Quantitative validation

공개 결과는 동일 시험 집합의 전체 기록을 집계하거나, 명시한 대표 시나리오의 검사 결과를 요약한 것입니다. 센서 기반 정렬, 주차 인식, 오프라인 경로 평가 및 합성 코드 검사를 구분합니다.

## Four-sensor alignment

| 항목 | 시험 조건 |
|---|---|
| 센서 | 네 모서리에 배치한 RTX 기반 2D LiDAR 4개 |
| 정렬 대상 | 로봇 1모듈, 동일 차량의 동일 차축 |
| 운동 모델 | 이상적인 비미끄럼 바퀴 명령 적분 |
| 초기 각도 | −14°, −10°, −5°, 0°, +5°, +10°, +14° |

| 추정 설정 | 종방향 5–95% 분위수 중점 |
| 제어 | 중심선 접근, 직선 진입, 재측정·미세 보정 |
| 종료 평가 | 센서 확인, 위치·각도 허용 범위, 타이어 외곽 이동 검사 |

| 시간 | 시작부터 정지까지 모의 시간, 이동·조향·관측 틱 포함 |

### Metrics

평균 절대오차는 각 시행의 부호 있는 최종 오차 $e_i$에서 다음과 같이 계산합니다.

$$\mathrm{MAE}=\frac{1}{N}\sum_{i=1}^{N}|e_i|$$

| 지표 | 평균 절대오차 | 최대 절대오차 |
|---|---:|---:|
| 종방향 위치 | 0.085 mm | 0.133 mm |
| 횡방향 위치 | 2.109 mm | 3.779 mm |
| 방향 | 0.0023° | 0.0064° |

14회 모두 명시한 성공 기준을 충족했고 평균 전체 정렬 시간은 19.46초입니다. 수치는 동일 차량 모델의 RTX 관측·이상 운동학 시험 집합에 대한 값입니다. 위치·방향 오차는 시뮬레이터 기준 자세로 사후 계산하며, 현장 장비의 계측 정밀도와 별개입니다. CPU 계산에 소요된 실제 경과 시간은 모의 정렬 시간에 합산하지 않습니다.

공개 CSV는 선택한 고정 분위수 설정의 14개 시행 전체를 포함합니다. 다른 설정과의 우열이나 모든 차종에 대한 일반화 지표를 합산한 값으로 사용하지 않습니다.

## Selected retrieval paths

공개한 두 출차 시나리오는 저장 칸에서 인계 구역까지의 대표 경로입니다.

- 전체 차량·모듈 외곽의 충돌 샘플 0건
- 구간별 연속 분리거리 하한 양수
- 조향각과 바퀴 속도 위반 0건
- 조향 속도 및 바퀴 가속도 검사 통과
- 목표 위치 0.1 m 및 방향 2° 조건 충족

평가 영역은 오프라인 기하 검사와 바퀴 명령의 이상 운동학 적분입니다. 경로 길이와 검사 샘플 수는 `data/selected_route_results.json`에 수록했습니다. 대표 경로의 결과를 전체 주차장 임무 성공률로 합산하지 않습니다.

## Telemetry comparison tests

| 검사 | 확인 대상 |
|---|---|
| Identical states | 같은 상태의 차이 0 |
| Known displacement | 3–4–5 cm 위치 차이 계산 |
| Body coordinates | 로봇 방향 기준 종·횡 성분 |
| Time interpolation | 대응 시각의 상태 보간 |
| Wrapped heading | +179°와 −179° 사이 보간 |
| Identity checks | 좌표·시계·지도·시행·기준점 일관성 |
| No extrapolation | 보간 구간 바깥 입력 처리 |
| Missing samples | 긴 관측 공백 처리 |
| Clock reset | 시각 역행·중복 처리 |
| Numeric validation | 비정상 수치 처리 |

합성 입력을 이용한 독립 자동 검사 10개입니다. 정렬 시험 14회와 별개의 코드 검증입니다. 예제의 `--max-gap-s 0.2`는 샘플 보간 조건이며 로봇 정지 기준으로 사용하지 않습니다.

## Recalculate

```bash
python3 tools/summarize_results.py
python3 -m unittest discover -s tests -v
```

첫 명령은 공개 CSV에서 성공 수·최종 오차·시간을 재집계하고 제공된 요약값과 일치하는지 확인합니다. 로봇 모델과 센서 실행 환경 대신 결과 데이터의 계산 재현성을 제공합니다.
